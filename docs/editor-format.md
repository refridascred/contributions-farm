# Editor format

Reference notes for the editor-format module.

## Functions

- `ReportAccountPercent`: Express a report account count as a percentage.
- `BatchPeak`: Find the peak batch sample.
- `CommandRecordPercent`: Express a command record count as a percentage.
- `FarmPeak`: Find the peak farm sample.
- `IsProfileBatchesPowerOfTwo`: Check whether a profile batches size is a power of two.
