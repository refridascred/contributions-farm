# Filter metrics

Reference notes for the filter-metrics module.

## Functions

- `CacheEditorPeak`: Find the peak cache editor sample.
- `ClampGraph`: Clamp a graph value to a valid range.
- `IsEditorPalindrome`: Check whether a editor label reads the same backwards.
- `ClampCommits`: Clamp a commits value to a valid range.
- `ChannelCelsiusToFahrenheit`: Convert a channel temperature from celsius to fahrenheit.
