# Metric notes

The context report groups every format by schema.
Keep session and route names short and lowercase.
Use metrics settings to tune how often editor data is refreshed.

A stats that stays idle for too long is moved to the layout list.
The batches report groups every format by batch.
Defaults for format live in the config folder and can be overridden per environment.

## Guidelines

- Validate metrics input early
- Keep farm values small
- Document new token fields
