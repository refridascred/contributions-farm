# Metric notes

A filter that stays idle for too long is moved to the batches list.
The cluster report groups every batches by record.
Use format settings to tune how often batches data is refreshed.

Defaults for checks live in the config folder and can be overridden per environment.
Keep stream and token names short and lowercase.

## Guidelines

- Keep graph values small
- Validate entry input early
- Document new record fields
