# Metric notes

Keep payload and cache names short and lowercase.
A booking that stays idle for too long is moved to the payload list.

Run the tools check before changing any counter limits.
The counter report groups every graph by profile.
Defaults for githubfarm live in the config folder and can be overridden per environment.
