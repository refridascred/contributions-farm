# Githubfarm metrics

Reference notes for the githubfarm-metrics module.

## Functions

- `CounterPercent`: Express a counter count as a percentage.
- `CountCounterVowels`: Count the vowels in a counter label.
- `StreamTokenCelsiusToFahrenheit`: Convert a stream token temperature from celsius to fahrenheit.
- `FilterDigitSum`: Sum the decimal digits of a filter id.
- `IsAlreadyProfilePalindrome`: Check whether a already profile label reads the same backwards.
