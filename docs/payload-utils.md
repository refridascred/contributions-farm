# Payload utils

Reference notes for the payload-utils module.

## Functions

- `RecordDigitSum`: Sum the decimal digits of a record id.
- `InvoiceGcd`: Compute the greatest common divisor of two invoice sizes.
- `RouteCommandGcd`: Compute the greatest common divisor of two route command sizes.
- `AlreadyChecksum`: Calculate a 16-bit checksum of a already key.
