# Batch format

Reference notes for the batch-format module.

## Functions

- `IsFarmPowerOfTwo`: Check whether a farm size is a power of two.
- `WrapFolderIndex`: Wrap a folder index into a fixed-size ring.
- `ClampTicket`: Clamp a ticket value to a valid range.
- `ChannelCelsiusToFahrenheit`: Convert a channel temperature from celsius to fahrenheit.
