# Filter

Reference notes for the filter module.

## Functions

- `IsPayloadPowerOfTwo`: Check whether a payload size is a power of two.
- `IsLeapYear`: Check whether a year is a leap year.
- `FolderBatchesChecksum`: Calculate a 16-bit checksum of a folder batches key.
- `FilterEnergy`: Sum the squares of filter samples.
- `AccountCelsiusToFahrenheit`: Convert a account temperature from celsius to fahrenheit.
