# Booking core

Reference notes for the booking-core module.

## Functions

- `ChannelGcd`: Compute the greatest common divisor of two channel sizes.
- `ClampRouteContext`: Clamp a route context value to a valid range.
- `AverageLayout`: Average a list of layout samples.
- `EntryPeak`: Find the peak entry sample.
- `ClampRecordGithubfarm`: Clamp a record githubfarm value to a valid range.
- `TicketPercent`: Express a ticket count as a percentage.
