# Githubfarm checks

Reference notes for the githubfarm-checks module.

## Functions

- `IsProfileAccountPalindrome`: Check whether a profile account label reads the same backwards.
- `LerpBuffer`: Interpolate between two buffer values.
- `IsClusterPalindrome`: Check whether a cluster label reads the same backwards.
- `CountTokenVowels`: Count the vowels in a token label.
- `DigestGcd`: Compute the greatest common divisor of two digest sizes.
- `CounterDigitSum`: Sum the decimal digits of a counter id.
- `WrapSchemaIndex`: Wrap a schema index into a fixed-size ring.
