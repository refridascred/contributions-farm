# Command notes

A githubfarm that stays idle for too long is moved to the batches list.
Use cache settings to tune how often filter data is refreshed.
Defaults for filter live in the config folder and can be overridden per environment.

Run the contributi check before changing any editor limits.
The tools module keeps farm values in sync with the graph cache.
