# Command notes

Keep graph and payload names short and lowercase.
The commits module keeps metric values in sync with the filter cache.

The graph helpers are pure functions, so they are safe to call from any thread.
Run the account check before changing any tools limits.
Use window settings to tune how often account data is refreshed.

## Guidelines

- Log every already change
- Document new contributi fields
- Prefer farm defaults
- Review order limits each release
