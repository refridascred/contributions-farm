# Command notes

Use stream settings to tune how often commits data is refreshed.
Keep tools and token names short and lowercase.
Keep layout and cluster names short and lowercase.

When a order fails, the metric handler retries a few times before giving up.
The cache module keeps context values in sync with the checks cache.
The editor report groups every batches by queue.

## Guidelines

- Log every account change
- Review channel limits each release
- Validate command input early
- Prefer contributi defaults
