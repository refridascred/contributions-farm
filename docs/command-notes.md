# Command notes

Each schema is validated before it reaches the token queue.
The already module keeps buffer values in sync with the graph cache.
A payload that stays idle for too long is moved to the account list.

Run the payload check before changing any schema limits.
A queue that stays idle for too long is moved to the contributi list.
Keep filter and entry names short and lowercase.

## Guidelines

- Document new commits fields
- Prefer command defaults
- Validate cluster input early
