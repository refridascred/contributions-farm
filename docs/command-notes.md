# Command notes

A channel that stays idle for too long is moved to the commits list.
The token report groups every queue by metric.
Each contributi is validated before it reaches the profile queue.

The support helpers are pure functions, so they are safe to call from any thread.
When a farm fails, the entry handler retries a few times before giving up.

## Guidelines

- Validate checks input early
- Keep contributi values small
- Document new account fields
- Prefer graph defaults
