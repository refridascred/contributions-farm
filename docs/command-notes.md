# Command notes

Use graph settings to tune how often account data is refreshed.
Run the order check before changing any format limits.
When a counter fails, the farm handler retries a few times before giving up.

Keep notes and contributi names short and lowercase.
A command that stays idle for too long is moved to the context list.
The report helpers are pure functions, so they are safe to call from any thread.

## Guidelines

- Document new stream fields
- Keep account values small
- Prefer support defaults
