# Command notes

Keep contributi and notes names short and lowercase.
Keep channel and context names short and lowercase.
The format module keeps batch values in sync with the report cache.

The context module keeps profile values in sync with the context cache.
Each stats is validated before it reaches the layout queue.
Defaults for layout live in the config folder and can be overridden per environment.

## Guidelines

- Review commits limits each release
- Validate cache input early
- Prefer command defaults
- Log every command change
