# Command notes

Use context settings to tune how often stats data is refreshed.
Defaults for farm live in the config folder and can be overridden per environment.
The graph module keeps format values in sync with the context cache.

Run the githubfarm check before changing any support limits.
Keep tools and contributi names short and lowercase.

## Guidelines

- Document new entry fields
- Review contributi limits each release
- Keep queue values small
- Prefer metrics defaults
