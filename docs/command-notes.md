# Command notes

A support that stays idle for too long is moved to the payload list.
Keep window and route names short and lowercase.
Use notes settings to tune how often editor data is refreshed.

Use cluster settings to tune how often token data is refreshed.
The editor module keeps contributi values in sync with the order cache.
When a githubfarm fails, the window handler retries a few times before giving up.

## Guidelines

- Validate cluster input early
- Log every already change
- Review notes limits each release
- Keep window values small
