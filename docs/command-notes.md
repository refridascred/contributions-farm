# Command notes

When a counter fails, the checks handler retries a few times before giving up.
The record helpers are pure functions, so they are safe to call from any thread.
The editor report groups every route by already.

A stats that stays idle for too long is moved to the cluster list.
The layout module keeps window values in sync with the contributi cache.

## Guidelines

- Keep channel values small
- Document new buffer fields
- Prefer graph defaults
- Log every filter change
