# Command notes

Keep counter and cache names short and lowercase.
A contributi that stays idle for too long is moved to the report list.
The format module keeps contributi values in sync with the farm cache.

When a order fails, the graph handler retries a few times before giving up.
Defaults for profile live in the config folder and can be overridden per environment.

## Guidelines

- Log every filter change
- Prefer schema defaults
- Document new filter fields
- Review farm limits each release
