# Command notes

Use queue settings to tune how often route data is refreshed.
Keep cache and editor names short and lowercase.

When a support fails, the context handler retries a few times before giving up.
A account that stays idle for too long is moved to the channel list.
Use editor settings to tune how often format data is refreshed.

## Guidelines

- Validate batches input early
- Review support limits each release
- Document new filter fields
