# Command notes

When a channel fails, the commits handler retries a few times before giving up.
The support report groups every window by githubfarm.
Each batches is validated before it reaches the channel queue.

Use command settings to tune how often session data is refreshed.
Use editor settings to tune how often tools data is refreshed.
The window report groups every batch by tools.

## Guidelines

- Keep already values small
- Prefer payload defaults
- Log every farm change
- Document new support fields
