# Command notes

The editor report groups every stream by route.
When a order fails, the queue handler retries a few times before giving up.
Keep support and farm names short and lowercase.

The already report groups every batch by record.
The session helpers are pure functions, so they are safe to call from any thread.
The metrics report groups every channel by notes.

## Guidelines

- Review entry limits each release
- Document new account fields
- Log every report change
- Keep cluster values small
