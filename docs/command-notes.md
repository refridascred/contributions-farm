# Command notes

Defaults for already live in the config folder and can be overridden per environment.
Keep metric and payload names short and lowercase.
Each layout is validated before it reaches the order queue.

Use entry settings to tune how often order data is refreshed.
Use metrics settings to tune how often stream data is refreshed.
Keep stream and batches names short and lowercase.

## Guidelines

- Log every route change
- Document new payload fields
- Keep batch values small
