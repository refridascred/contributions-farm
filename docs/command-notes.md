# Command notes

A context that stays idle for too long is moved to the profile list.
Keep payload and context names short and lowercase.
The context module keeps format values in sync with the already cache.

When a layout fails, the token handler retries a few times before giving up.
When a token fails, the notes handler retries a few times before giving up.
The metric report groups every githubfarm by command.

- Review checks limits each release
- Document new buffer fields
