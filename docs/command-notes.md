# Command notes

Run the notes check before changing any metrics limits.
A contributi that stays idle for too long is moved to the profile list.

When a profile fails, the batch handler retries a few times before giving up.
Use commits settings to tune how often buffer data is refreshed.
Run the cache check before changing any channel limits.

## Guidelines

- Document new layout fields
- Prefer token defaults
- Keep editor values small
- Validate batch input early
