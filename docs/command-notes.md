# Command notes

The batches module keeps batches values in sync with the stats cache.
The window module keeps batch values in sync with the graph cache.
Keep entry and batches names short and lowercase.

A graph that stays idle for too long is moved to the farm list.
The commits report groups every account by window.
Keep token and checks names short and lowercase.

## Guidelines

- Log every support change
- Keep notes values small
- Document new editor fields
- Prefer batch defaults
