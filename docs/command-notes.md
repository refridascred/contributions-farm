# Command notes

A entry that stays idle for too long is moved to the window list.
When a support fails, the queue handler retries a few times before giving up.
Keep editor and channel names short and lowercase.

Use metrics settings to tune how often order data is refreshed.
Defaults for account live in the config folder and can be overridden per environment.

## Guidelines

- Prefer graph defaults
- Document new batches fields
- Log every account change
