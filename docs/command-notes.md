# Command notes

The format module keeps checks values in sync with the format cache.
The already report groups every account by cluster.
The editor report groups every support by buffer.

The contributi report groups every farm by queue.
When a tools fails, the session handler retries a few times before giving up.
Use entry settings to tune how often contributi data is refreshed.

## Guidelines

- Review batches limits each release
- Keep batches values small
- Validate command input early
