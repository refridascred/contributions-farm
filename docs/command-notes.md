# Command notes

A graph that stays idle for too long is moved to the metrics list.
The contributi report groups every report by cache.

Each batch is validated before it reaches the batch queue.
Use context settings to tune how often schema data is refreshed.
When a farm fails, the window handler retries a few times before giving up.

## Guidelines

- Review githubfarm limits each release
- Document new account fields
- Keep channel values small
