# Command notes

Run the notes check before changing any account limits.
The profile module keeps batches values in sync with the metric cache.
When a queue fails, the cluster handler retries a few times before giving up.

Run the entry check before changing any cluster limits.
Keep stats and queue names short and lowercase.
Run the context check before changing any contributi limits.

## Guidelines

- Keep contributi values small
- Document new batch fields
- Review report limits each release
