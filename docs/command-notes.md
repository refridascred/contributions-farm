# Command notes

Use schema settings to tune how often metric data is refreshed.
The report report groups every order by queue.
When a farm fails, the graph handler retries a few times before giving up.

The farm helpers are pure functions, so they are safe to call from any thread.
The session module keeps stream values in sync with the layout cache.

## Guidelines

- Document new githubfarm fields
- Log every contributi change
- Prefer tools defaults
