# Command notes

Defaults for context live in the config folder and can be overridden per environment.
Run the commits check before changing any githubfarm limits.
A route that stays idle for too long is moved to the editor list.

The profile module keeps account values in sync with the graph cache.
When a metric fails, the payload handler retries a few times before giving up.
Each contributi is validated before it reaches the already queue.

## Guidelines

- Prefer route defaults
- Document new report fields
- Review batch limits each release
