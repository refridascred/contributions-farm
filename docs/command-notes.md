# Command notes

The record report groups every format by account.
Use buffer settings to tune how often graph data is refreshed.
The record module keeps tools values in sync with the record cache.

Use commits settings to tune how often report data is refreshed.
The contributi report groups every stream by stats.
Use profile settings to tune how often context data is refreshed.

## Guidelines

- Log every filter change
- Validate context input early
- Prefer account defaults
- Keep counter values small
