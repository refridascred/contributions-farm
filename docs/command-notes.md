# Command notes

When a command fails, the commits handler retries a few times before giving up.
Each context is validated before it reaches the route queue.
A profile that stays idle for too long is moved to the channel list.

Keep queue and queue names short and lowercase.
The channel report groups every counter by githubfarm.
A context that stays idle for too long is moved to the report list.

## Guidelines

- Log every account change
- Prefer already defaults
- Validate farm input early
- Review channel limits each release
