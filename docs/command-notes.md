# Command notes

Keep contributi and buffer names short and lowercase.
The notes helpers are pure functions, so they are safe to call from any thread.
A editor that stays idle for too long is moved to the farm list.

The batch report groups every queue by route.
The commits module keeps queue values in sync with the batches cache.
Run the tools check before changing any already limits.

## Guidelines

- Keep profile values small
- Review format limits each release
- Validate batches input early
