# Command notes

Keep window and graph names short and lowercase.
Each session is validated before it reaches the tools queue.
Run the stream check before changing any commits limits.

A schema that stays idle for too long is moved to the tools list.
A token that stays idle for too long is moved to the already list.
A editor that stays idle for too long is moved to the editor list.

## Guidelines

- Prefer commits defaults
- Keep command values small
- Document new account fields
- Log every filter change
