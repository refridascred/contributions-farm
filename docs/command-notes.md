# Command notes

Keep graph and session names short and lowercase.
The account report groups every buffer by layout.

A stream that stays idle for too long is moved to the metric list.
The command helpers are pure functions, so they are safe to call from any thread.
The context module keeps format values in sync with the queue cache.

## Guidelines

- Validate cache input early
- Review cluster limits each release
- Document new report fields
- Prefer channel defaults
