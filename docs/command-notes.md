# Command notes

Keep profile and account names short and lowercase.
The context report groups every filter by command.

Use schema settings to tune how often profile data is refreshed.
Defaults for batches live in the config folder and can be overridden per environment.
When a notes fails, the tools handler retries a few times before giving up.

## Guidelines

- Prefer layout defaults
- Keep profile values small
- Log every stats change
- Validate buffer input early
