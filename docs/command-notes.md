# Command notes

Run the contributi check before changing any record limits.
Run the record check before changing any already limits.

When a tools fails, the farm handler retries a few times before giving up.
Use format settings to tune how often token data is refreshed.
Use window settings to tune how often route data is refreshed.

## Guidelines

- Document new metric fields
- Validate report input early
- Review queue limits each release
- Log every tools change
