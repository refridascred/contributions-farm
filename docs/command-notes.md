# Command notes

A window that stays idle for too long is moved to the window list.
When a layout fails, the graph handler retries a few times before giving up.
Keep stats and command names short and lowercase.

The token report groups every metrics by account.
Each queue is validated before it reaches the batches queue.

## Guidelines

- Keep token values small
- Review account limits each release
- Prefer farm defaults
- Validate layout input early
