# Command notes

Use record settings to tune how often checks data is refreshed.
Use payload settings to tune how often report data is refreshed.

Keep session and payload names short and lowercase.
Defaults for entry live in the config folder and can be overridden per environment.
The tools report groups every batch by support.

## Guidelines

- Log every metrics change
- Keep stream values small
- Review checks limits each release
- Prefer profile defaults
