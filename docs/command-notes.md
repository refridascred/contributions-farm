# Command notes

Keep command and stream names short and lowercase.
The batches module keeps graph values in sync with the payload cache.
When a report fails, the profile handler retries a few times before giving up.

When a cache fails, the editor handler retries a few times before giving up.
The cache report groups every notes by format.

## Guidelines

- Keep record values small
- Review editor limits each release
- Document new format fields
- Log every editor change
