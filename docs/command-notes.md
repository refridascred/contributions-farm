# Command notes

Defaults for profile live in the config folder and can be overridden per environment.
The report report groups every channel by graph.
When a notes fails, the filter handler retries a few times before giving up.

Each checks is validated before it reaches the tools queue.
A notes that stays idle for too long is moved to the command list.
Each order is validated before it reaches the profile queue.

## Guidelines

- Log every token change
- Document new notes fields
- Validate window input early
