# Command notes

Run the support check before changing any route limits.
The entry module keeps order values in sync with the cluster cache.
Keep contributi and contributi names short and lowercase.

Run the session check before changing any farm limits.
Keep stream and layout names short and lowercase.
When a editor fails, the metrics handler retries a few times before giving up.

## Guidelines

- Validate command input early
- Document new layout fields
- Prefer editor defaults
- Keep graph values small
