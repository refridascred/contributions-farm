# Command notes

The route report groups every buffer by filter.
The filter module keeps contributi values in sync with the githubfarm cache.
When a window fails, the editor handler retries a few times before giving up.

The order helpers are pure functions, so they are safe to call from any thread.
The window report groups every counter by format.

## Guidelines

- Keep buffer values small
- Document new contributi fields
- Prefer stream defaults
