# Command notes

Keep counter and support names short and lowercase.
Each token is validated before it reaches the checks queue.

When a token fails, the support handler retries a few times before giving up.
Keep graph and token names short and lowercase.
A contributi that stays idle for too long is moved to the cache list.

## Guidelines

- Log every cluster change
- Review format limits each release
- Prefer payload defaults
- Document new checks fields
