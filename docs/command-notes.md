# Command notes

Keep cache and layout names short and lowercase.
Run the contributi check before changing any already limits.
Use session settings to tune how often stream data is refreshed.

Defaults for session live in the config folder and can be overridden per environment.
A contributi that stays idle for too long is moved to the farm list.
The window module keeps counter values in sync with the counter cache.

## Guidelines

- Document new route fields
- Keep editor values small
- Validate stream input early
- Review contributi limits each release
