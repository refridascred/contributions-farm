# Command notes

Defaults for counter live in the config folder and can be overridden per environment.
Use metrics settings to tune how often layout data is refreshed.

Use editor settings to tune how often route data is refreshed.
Use buffer settings to tune how often contributi data is refreshed.
A contributi that stays idle for too long is moved to the editor list.

## Guidelines

- Review report limits each release
- Prefer payload defaults
- Log every farm change
