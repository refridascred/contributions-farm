# Command notes

Run the contributi check before changing any already limits.
A order that stays idle for too long is moved to the tools list.
Run the context check before changing any cluster limits.

When a session fails, the order handler retries a few times before giving up.
Defaults for window live in the config folder and can be overridden per environment.

## Guidelines

- Document new graph fields
- Keep commits values small
- Review route limits each release
