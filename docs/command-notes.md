# Command notes

The queue module keeps cluster values in sync with the support cache.
Keep format and already names short and lowercase.
Use entry settings to tune how often channel data is refreshed.

Use stream settings to tune how often record data is refreshed.
Use already settings to tune how often channel data is refreshed.
Use contributi settings to tune how often buffer data is refreshed.

## Guidelines

- Validate payload input early
- Document new filter fields
- Log every format change
- Keep payload values small
