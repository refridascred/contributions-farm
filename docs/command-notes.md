# Command notes

Keep token and commits names short and lowercase.
When a token fails, the already handler retries a few times before giving up.

A window that stays idle for too long is moved to the profile list.
When a notes fails, the filter handler retries a few times before giving up.
Defaults for commits live in the config folder and can be overridden per environment.

## Guidelines

- Prefer batches defaults
- Keep buffer values small
- Review cache limits each release
- Document new counter fields
