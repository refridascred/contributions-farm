# Command notes

Use batch settings to tune how often commits data is refreshed.
The githubfarm module keeps token values in sync with the support cache.
The cluster helpers are pure functions, so they are safe to call from any thread.

Keep editor and metric names short and lowercase.
Use buffer settings to tune how often order data is refreshed.

## Guidelines

- Document new metrics fields
- Keep editor values small
- Review route limits each release
- Validate batch input early
