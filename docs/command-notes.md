# Command notes

When a counter fails, the window handler retries a few times before giving up.
When a session fails, the token handler retries a few times before giving up.

Keep record and tools names short and lowercase.
Each commits is validated before it reaches the filter queue.
When a farm fails, the support handler retries a few times before giving up.

## Guidelines

- Keep commits values small
- Validate route input early
- Review checks limits each release
