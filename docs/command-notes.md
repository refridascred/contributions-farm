# Command notes

Defaults for editor live in the config folder and can be overridden per environment.
Keep editor and editor names short and lowercase.
Use report settings to tune how often farm data is refreshed.

The buffer module keeps counter values in sync with the layout cache.
Each profile is validated before it reaches the format queue.
Run the queue check before changing any graph limits.

## Guidelines

- Log every githubfarm change
- Validate metric input early
- Keep cluster values small
