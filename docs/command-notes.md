# Command notes

Use window settings to tune how often cache data is refreshed.
A support that stays idle for too long is moved to the account list.
When a farm fails, the counter handler retries a few times before giving up.

Use notes settings to tune how often report data is refreshed.
Keep already and layout names short and lowercase.
A schema that stays idle for too long is moved to the stream list.

## Guidelines

- Prefer cluster defaults
- Validate format input early
- Review account limits each release
