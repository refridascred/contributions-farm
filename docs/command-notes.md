# Command notes

A cluster that stays idle for too long is moved to the format list.
Run the report check before changing any record limits.
The schema helpers are pure functions, so they are safe to call from any thread.

A githubfarm that stays idle for too long is moved to the cluster list.
Keep batch and format names short and lowercase.
