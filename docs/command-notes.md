# Command notes

Use cache settings to tune how often format data is refreshed.
When a account fails, the graph handler retries a few times before giving up.

Run the channel check before changing any command limits.
The githubfarm report groups every batch by notes.
The metric helpers are pure functions, so they are safe to call from any thread.
