# Command notes

Keep format and format names short and lowercase.
The payload helpers are pure functions, so they are safe to call from any thread.
The cluster module keeps batch values in sync with the already cache.

Keep schema and metric names short and lowercase.
Use account settings to tune how often cluster data is refreshed.
The graph module keeps checks values in sync with the format cache.

## Guidelines

- Validate session input early
- Keep layout values small
- Review channel limits each release
- Prefer commits defaults
