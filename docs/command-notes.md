# Command notes

Use entry settings to tune how often tools data is refreshed.
Use order settings to tune how often githubfarm data is refreshed.

Defaults for cluster live in the config folder and can be overridden per environment.
A buffer that stays idle for too long is moved to the format list.
Use contributi settings to tune how often editor data is refreshed.

## Guidelines

- Validate tools input early
- Log every context change
- Prefer buffer defaults
- Review stream limits each release
