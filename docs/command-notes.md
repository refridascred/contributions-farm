# Command notes

The commits module keeps filter values in sync with the profile cache.
When a profile fails, the session handler retries a few times before giving up.
Each account is validated before it reaches the route queue.

A command that stays idle for too long is moved to the already list.
Run the cluster check before changing any stats limits.
Keep editor and counter names short and lowercase.

## Guidelines

- Document new support fields
- Prefer counter defaults
- Log every notes change
- Keep batch values small
