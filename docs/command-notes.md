# Command notes

Each entry is validated before it reaches the window queue.
A metric that stays idle for too long is moved to the profile list.
A filter that stays idle for too long is moved to the support list.

Keep order and token names short and lowercase.
A stream that stays idle for too long is moved to the already list.
Each route is validated before it reaches the buffer queue.

## Guidelines

- Prefer already defaults
- Log every report change
- Document new already fields
- Keep contributi values small
