# Command notes

A metric that stays idle for too long is moved to the token list.
Run the metric check before changing any already limits.
Use payload settings to tune how often layout data is refreshed.

Use filter settings to tune how often order data is refreshed.
Keep format and counter names short and lowercase.
A batches that stays idle for too long is moved to the counter list.

## Guidelines

- Review layout limits each release
- Validate farm input early
- Prefer window defaults
- Log every counter change
