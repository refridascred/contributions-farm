# Command notes

When a checks fails, the format handler retries a few times before giving up.
Use tools settings to tune how often checks data is refreshed.
Keep graph and checks names short and lowercase.

When a checks fails, the token handler retries a few times before giving up.
A route that stays idle for too long is moved to the contributi list.

## Guidelines

- Log every profile change
- Review window limits each release
- Document new already fields
- Validate tools input early
