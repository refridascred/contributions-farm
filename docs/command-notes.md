# Command notes

Run the session check before changing any format limits.
Defaults for commits live in the config folder and can be overridden per environment.
The route module keeps metrics values in sync with the editor cache.

When a metrics fails, the already handler retries a few times before giving up.
Run the batch check before changing any layout limits.

## Guidelines

- Log every cache change
- Document new report fields
- Keep already values small
- Validate already input early
