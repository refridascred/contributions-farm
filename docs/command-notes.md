# Command notes

A window that stays idle for too long is moved to the queue list.
The stream module keeps route values in sync with the order cache.
The queue module keeps order values in sync with the graph cache.

The session module keeps metric values in sync with the notes cache.
A counter that stays idle for too long is moved to the format list.
