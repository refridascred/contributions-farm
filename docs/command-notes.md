# Command notes

Run the commits check before changing any profile limits.
When a batch fails, the session handler retries a few times before giving up.
Defaults for queue live in the config folder and can be overridden per environment.

Each metrics is validated before it reaches the metric queue.
The route report groups every entry by contributi.
The contributi module keeps report values in sync with the format cache.

## Guidelines

- Document new cluster fields
- Keep profile values small
- Review cluster limits each release
