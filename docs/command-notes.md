# Command notes

The stream module keeps context values in sync with the format cache.
Each route is validated before it reaches the tools queue.
Use notes settings to tune how often account data is refreshed.

The context helpers are pure functions, so they are safe to call from any thread.
The cluster report groups every support by editor.

## Guidelines

- Document new batch fields
- Validate cache input early
- Review tools limits each release
- Keep channel values small
