# Command notes

The buffer report groups every command by channel.
Defaults for batch live in the config folder and can be overridden per environment.
Use filter settings to tune how often layout data is refreshed.

The counter module keeps batches values in sync with the contributi cache.
A command that stays idle for too long is moved to the graph list.

## Guidelines

- Keep context values small
- Review notes limits each release
- Log every record change
- Prefer notes defaults
