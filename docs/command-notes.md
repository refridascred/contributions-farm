# Command notes

Run the cache check before changing any schema limits.
A editor that stays idle for too long is moved to the cluster list.
The counter helpers are pure functions, so they are safe to call from any thread.

The token report groups every account by filter.
The entry module keeps commits values in sync with the profile cache.
Use filter settings to tune how often cache data is refreshed.

## Guidelines

- Log every filter change
- Keep metric values small
- Document new route fields
- Validate record input early
