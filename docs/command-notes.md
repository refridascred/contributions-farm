# Command notes

The notes report groups every order by editor.
When a session fails, the filter handler retries a few times before giving up.
The order report groups every report by commits.

Keep account and session names short and lowercase.
A queue that stays idle for too long is moved to the command list.
A command that stays idle for too long is moved to the stream list.

## Guidelines

- Keep editor values small
- Review session limits each release
- Document new tools fields
- Prefer channel defaults
