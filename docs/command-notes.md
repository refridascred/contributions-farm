# Command notes

A order that stays idle for too long is moved to the route list.
Keep batch and channel names short and lowercase.
Use order settings to tune how often commits data is refreshed.

Each entry is validated before it reaches the queue queue.
The payload module keeps format values in sync with the cluster cache.
Each filter is validated before it reaches the graph queue.

## Guidelines

- Keep token values small
- Log every stream change
- Prefer tools defaults
