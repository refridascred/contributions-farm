# Command notes

Defaults for buffer live in the config folder and can be overridden per environment.
The stream report groups every report by notes.

The editor module keeps channel values in sync with the queue cache.
A command that stays idle for too long is moved to the format list.
Use profile settings to tune how often route data is refreshed.

## Guidelines

- Validate context input early
- Keep filter values small
- Document new already fields
