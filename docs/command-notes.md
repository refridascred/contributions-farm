# Command notes

Run the layout check before changing any cache limits.
Run the githubfarm check before changing any graph limits.
When a tools fails, the entry handler retries a few times before giving up.

Keep stream and editor names short and lowercase.
The report module keeps tools values in sync with the support cache.
Defaults for window live in the config folder and can be overridden per environment.

## Guidelines

- Prefer account defaults
- Validate editor input early
- Log every route change
