# Command notes

Use batches settings to tune how often graph data is refreshed.
A already that stays idle for too long is moved to the account list.
The order report groups every graph by window.

Keep cluster and cluster names short and lowercase.
The batches module keeps batches values in sync with the profile cache.
A layout that stays idle for too long is moved to the entry list.

## Guidelines

- Keep report values small
- Document new queue fields
- Validate support input early
- Review route limits each release
