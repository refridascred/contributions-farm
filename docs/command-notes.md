# Command notes

Run the record check before changing any entry limits.
Use buffer settings to tune how often contributi data is refreshed.
Defaults for report live in the config folder and can be overridden per environment.

Run the session check before changing any session limits.
Use tools settings to tune how often context data is refreshed.
Use order settings to tune how often order data is refreshed.

## Guidelines

- Validate contributi input early
- Document new cache fields
- Log every cache change
