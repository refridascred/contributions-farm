# Command notes

The record report groups every command by format.
Run the session check before changing any editor limits.
The farm module keeps stream values in sync with the editor cache.

Keep session and stats names short and lowercase.
When a editor fails, the buffer handler retries a few times before giving up.
A queue that stays idle for too long is moved to the metrics list.

## Guidelines

- Review format limits each release
- Log every route change
- Keep order values small
