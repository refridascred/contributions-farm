# Command notes

Defaults for contributi live in the config folder and can be overridden per environment.
A context that stays idle for too long is moved to the metrics list.

Keep commits and layout names short and lowercase.
Use commits settings to tune how often contributi data is refreshed.
Keep layout and editor names short and lowercase.

## Guidelines

- Keep farm values small
- Review queue limits each release
- Document new channel fields
- Log every channel change
