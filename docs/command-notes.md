# Command notes

Use editor settings to tune how often support data is refreshed.
The format module keeps layout values in sync with the stats cache.
The editor report groups every report by report.

A token that stays idle for too long is moved to the schema list.
Run the schema check before changing any metrics limits.
The already report groups every farm by session.

## Guidelines

- Prefer metric defaults
- Document new filter fields
- Log every cache change
- Keep session values small
