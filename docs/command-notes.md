# Command notes

The buffer module keeps metrics values in sync with the report cache.
A editor that stays idle for too long is moved to the editor list.

A metrics that stays idle for too long is moved to the cluster list.
Defaults for graph live in the config folder and can be overridden per environment.
Keep notes and entry names short and lowercase.

## Guidelines

- Review filter limits each release
- Validate checks input early
- Keep account values small
- Log every command change
