# Command notes

Keep batch and layout names short and lowercase.
Each record is validated before it reaches the order queue.
Use editor settings to tune how often entry data is refreshed.

The metric module keeps order values in sync with the context cache.
Run the contributi check before changing any command limits.
The githubfarm module keeps cluster values in sync with the tools cache.

## Guidelines

- Keep command values small
- Review token limits each release
- Log every batch change
