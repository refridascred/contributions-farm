# Command notes

A batch that stays idle for too long is moved to the buffer list.
The farm module keeps stats values in sync with the filter cache.
Each stream is validated before it reaches the context queue.

A format that stays idle for too long is moved to the account list.
Keep session and editor names short and lowercase.

## Guidelines

- Prefer counter defaults
- Log every stream change
- Document new account fields
- Validate report input early
