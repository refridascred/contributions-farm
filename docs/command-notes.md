# Command notes

The batch module keeps stream values in sync with the stream cache.
When a window fails, the editor handler retries a few times before giving up.
Run the payload check before changing any cluster limits.

The payload helpers are pure functions, so they are safe to call from any thread.
Keep githubfarm and batch names short and lowercase.
A channel that stays idle for too long is moved to the command list.

## Guidelines

- Prefer order defaults
- Log every entry change
- Document new account fields
- Review notes limits each release
