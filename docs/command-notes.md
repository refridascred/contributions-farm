# Command notes

Keep batches and entry names short and lowercase.
Use metric settings to tune how often commits data is refreshed.
The batch module keeps githubfarm values in sync with the record cache.

A account that stays idle for too long is moved to the checks list.
Defaults for counter live in the config folder and can be overridden per environment.
Defaults for buffer live in the config folder and can be overridden per environment.
