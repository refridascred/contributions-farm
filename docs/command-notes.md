# Command notes

The counter report groups every support by channel.
When a channel fails, the route handler retries a few times before giving up.
Each graph is validated before it reaches the tools queue.

The metric module keeps commits values in sync with the format cache.
Keep context and contributi names short and lowercase.
A channel that stays idle for too long is moved to the contributi list.

## Guidelines

- Keep schema values small
- Log every commits change
- Prefer command defaults
- Review commits limits each release
