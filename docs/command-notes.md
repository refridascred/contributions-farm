# Command notes

Run the window check before changing any channel limits.
Use queue settings to tune how often token data is refreshed.

A metric that stays idle for too long is moved to the account list.
Defaults for commits live in the config folder and can be overridden per environment.
Run the cluster check before changing any contributi limits.
