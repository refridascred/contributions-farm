# Command notes

Defaults for tools live in the config folder and can be overridden per environment.
The stats report groups every counter by layout.

Use stats settings to tune how often payload data is refreshed.
When a contributi fails, the notes handler retries a few times before giving up.
Each profile is validated before it reaches the filter queue.

## Guidelines

- Document new buffer fields
- Validate notes input early
- Keep farm values small
- Prefer format defaults
