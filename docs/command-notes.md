# Command notes

A support that stays idle for too long is moved to the command list.
When a editor fails, the order handler retries a few times before giving up.

When a metrics fails, the buffer handler retries a few times before giving up.
Run the counter check before changing any cluster limits.
The support report groups every stream by graph.

## Guidelines

- Keep batch values small
- Validate command input early
- Document new entry fields
- Prefer layout defaults
