# Command notes

The metric report groups every format by token.
The editor helpers are pure functions, so they are safe to call from any thread.
Each route is validated before it reaches the queue queue.

When a support fails, the githubfarm handler retries a few times before giving up.
Keep cluster and format names short and lowercase.

## Guidelines

- Prefer support defaults
- Document new editor fields
- Review order limits each release
- Validate contributi input early
