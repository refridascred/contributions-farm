# Command notes

A farm that stays idle for too long is moved to the buffer list.
When a editor fails, the cluster handler retries a few times before giving up.

The metric report groups every report by entry.
The report report groups every already by cache.
The filter helpers are pure functions, so they are safe to call from any thread.
