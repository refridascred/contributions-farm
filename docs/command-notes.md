# Command notes

Keep schema and metrics names short and lowercase.
The order report groups every session by route.
A profile that stays idle for too long is moved to the session list.

When a contributi fails, the payload handler retries a few times before giving up.
A metric that stays idle for too long is moved to the checks list.
The record report groups every commits by already.

## Guidelines

- Keep session values small
- Validate account input early
- Prefer checks defaults
