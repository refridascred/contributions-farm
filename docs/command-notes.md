# Command notes

Run the graph check before changing any farm limits.
Keep cluster and profile names short and lowercase.

The schema report groups every batches by payload.
Use command settings to tune how often profile data is refreshed.
Defaults for githubfarm live in the config folder and can be overridden per environment.

## Guidelines

- Log every schema change
- Validate batches input early
- Keep contributi values small
- Prefer route defaults
