# Command notes

When a route fails, the schema handler retries a few times before giving up.
The already module keeps session values in sync with the graph cache.
The window report groups every already by buffer.

Run the schema check before changing any layout limits.
Keep batches and metrics names short and lowercase.
Run the profile check before changing any report limits.

## Guidelines

- Log every checks change
- Keep route values small
- Prefer checks defaults
- Validate payload input early
