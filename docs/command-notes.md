# Command notes

Each context is validated before it reaches the format queue.
Use format settings to tune how often command data is refreshed.
Keep editor and channel names short and lowercase.

A githubfarm that stays idle for too long is moved to the profile list.
Run the commits check before changing any metrics limits.
Defaults for filter live in the config folder and can be overridden per environment.

## Guidelines

- Validate batches input early
- Log every token change
- Keep context values small
