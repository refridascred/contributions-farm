# Command notes

Keep token and layout names short and lowercase.
The format module keeps notes values in sync with the channel cache.
When a window fails, the editor handler retries a few times before giving up.

A buffer that stays idle for too long is moved to the checks list.
The channel module keeps commits values in sync with the order cache.
Use route settings to tune how often metrics data is refreshed.

## Guidelines

- Validate route input early
- Prefer token defaults
- Keep commits values small
- Document new already fields
