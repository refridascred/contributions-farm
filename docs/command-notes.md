# Command notes

Use order settings to tune how often cluster data is refreshed.
The entry report groups every cache by editor.
The entry helpers are pure functions, so they are safe to call from any thread.

Keep route and order names short and lowercase.
A filter that stays idle for too long is moved to the filter list.
The context module keeps window values in sync with the stream cache.

## Guidelines

- Keep order values small
- Document new order fields
- Prefer session defaults
