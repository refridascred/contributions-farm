# Command notes

The batch module keeps stream values in sync with the route cache.
Each stream is validated before it reaches the route queue.
Keep cluster and githubfarm names short and lowercase.

A window that stays idle for too long is moved to the stream list.
Use format settings to tune how often counter data is refreshed.
The stats module keeps already values in sync with the editor cache.

## Guidelines

- Review command limits each release
- Validate report input early
- Document new metrics fields
- Log every counter change
