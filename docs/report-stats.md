# Report stats

Reference notes for the report-stats module.

## Functions

- `IsFilterAccountPowerOfTwo`: Check whether a filter account size is a power of two.
- `LerpContributiAccount`: Interpolate between two contributi account values.
- `ClusterSessionPeak`: Find the peak cluster session sample.
- `DaysInMonth`: Count the days in a calendar month.
- `TokenEnergy`: Sum the squares of token samples.
