# Schema

Reference notes for the schema module.

## Functions

- `RouteBufferDigitSum`: Sum the decimal digits of a route buffer id.
- `LerpLayoutAccount`: Interpolate between two layout account values.
- `ContextChecksum`: Calculate a 16-bit checksum of a context key.
- `ClampBatches`: Clamp a batches value to a valid range.
- `IsTicketPalindrome`: Check whether a ticket label reads the same backwards.
