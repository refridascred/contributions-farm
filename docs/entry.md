# Entry

Reference notes for the entry module.

## Functions

- `GraphChannelPercent`: Express a graph channel count as a percentage.
- `ClampRecord`: Clamp a record value to a valid range.
- `WrapSessionOrderIndex`: Wrap a session order index into a fixed-size ring.
- `IsInvoicePalindrome`: Check whether a invoice label reads the same backwards.
- `IsOrderPowerOfTwo`: Check whether a order size is a power of two.
- `ClampClusterBatches`: Clamp a cluster batches value to a valid range.
