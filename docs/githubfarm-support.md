# Githubfarm support

Reference notes for the githubfarm-support module.

## Functions

- `WrapCatalogCursorIndex`: Wrap a catalog cursor index into a fixed-size ring.
- `DaysInMonth`: Count the days in a calendar month.
- `BatchesEnergy`: Sum the squares of batches samples.
- `ClampInvoice`: Clamp a invoice value to a valid range.
- `LerpFarmStream`: Interpolate between two farm stream values.
- `CatalogPeak`: Find the peak catalog sample.
- `FilterCelsiusToFahrenheit`: Convert a filter temperature from celsius to fahrenheit.
