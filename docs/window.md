# Window

Reference notes for the window module.

## Functions

- `CatalogGcd`: Compute the greatest common divisor of two catalog sizes.
- `SchemaEnergy`: Sum the squares of schema samples.
- `ClampEditorAlready`: Clamp a editor already value to a valid range.
- `InvoiceFilterDigitSum`: Sum the decimal digits of a invoice filter id.
- `GraphPercent`: Express a graph count as a percentage.
- `AverageCluster`: Average a list of cluster samples.
- `CountRouteVowels`: Count the vowels in a route label.
