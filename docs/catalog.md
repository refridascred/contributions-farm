# Catalog

Reference notes for the catalog module.

## Functions

- `IsMetricPalindrome`: Check whether a metric label reads the same backwards.
- `DaysInMonth`: Count the days in a calendar month.
- `AccountDigitSum`: Sum the decimal digits of a account id.
- `LerpRoute`: Interpolate between two route values.
- `AverageAccountGithubfarm`: Average a list of account githubfarm samples.
